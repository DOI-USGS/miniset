To get started:

  1. Load a GeoTIFF image (COG recommended)
  2. Load an ISD JSON file (or use embedded CSM state)
  3. Click Generate to project and display

💡 Supports Mars, Moon, and other planetary bodies

About: This tool visualizes planetary sensor model footprints using USGSCSM camera models. Load a GeoTIFF (with embedded CSM State from csminit) or provide a sidecar ISD JSON file. Powered by miniset C++ and USGSCSM compiled to WebAssembly.
